# ニュース番組モード（ずんだもんテックニュース）

## 1. ニュースを集める

- **WebSearch（Web 検索）は使わない。** 情報源は次の 2 サイトと、そこからリンクされた記事だけ
  1. Hacker News トップページ https://news.ycombinator.com
  2. はてなブックマーク テクノロジー人気エントリー https://b.hatena.ne.jp/hotentry/it
- ページは WebFetch で取得する。片方が取れなければ取れた方だけで進める
- 上位記事のタイトル・URL・ポイント数（HN）/ブックマーク数（はてブ）を集める

## 2. 5 本選ぶ

- 両方のサイトで話題のもの、反応（ポイント・コメント・ブクマ）が多いものを優先
- 同じ話題は 1 本にまとめる
- 分野（開発・インフラ・セキュリティ・AI・業界など）が偏らないようにする
- 求人、「Ask HN」などの質問投稿は除く
- 選んだ記事は**必ずリンク先を WebFetch で開いて**中身と数字を確認する。開けなかったらタイトルとサイト上の情報だけで短くまとめ、報告でその旨を書く

## 3. 原稿（`news/script.py`）を書き換える

```python
OUTPUT_NAME = "tech_news_YYYYMMDD"
THEME = dict(
    style="news",
    program="ずんだもん テックニュース",
    date="2026年11月7日（土）",
    date_short="11/7（土）",            # テロップ左の赤いラベル
    ticker="Hacker News・はてなブックマークで話題の技術ニュース　◆　見出し1　◆　見出し2　◆　…",
)
```

構成（各ニュース 14〜17 秒、全体 90〜100 秒）：

| シーン | 中身 |
|---|---|
| オープニング | `jingle=True, enter=True`。番組ロゴのカード、日付、「今日のひとこと」（全体の傾向を 1 文） |
| ニュース 1〜5 | 下の形 |
| エンディング | `title="今日のニュース"`。5 本の一覧（左寄せ）、ひとことの再確認、「また明日！」（左寄せ・ジャンプ） |

ニュースのシーン：

```python
dict(
    name="github", news_no=2, category="インフラ", cat_color="c",
    headline="[y]GitHub[/]、AIエージェント時代の\nGit保存基盤を新設計",   # 2 行・1 行 14 字以内
    source="出典：GitHub Blog\n[y]HN 193pt[/]・はてブで話題",            # 左下の出典欄
    parts=[
        ("続いてインフラ。", []),                    # 分野の前置き（つなぎ）
        ("GitHubが、…作り直したのだ。", [T(..., y=470, ...)]),   # 何が起きたか
        ("…への備えで、", [T(..., y=650, ...)]),                 # 背景・なぜ話題か
        ("…さばけたそうなのだ。", [Card(..., y=760, ...)]),       # 数字で印象づける
    ],
),
```

- `cat_color`：開発 `y`、インフラ `c`、セキュリティ `r`、AI `p`、業界 `g` など、ニュースごとに変える
- 見出し帯は白地なので、マークアップの色は自動で濃い色に置き換わる
- 一般にあまり知られていない用語・ツール名には、画面に `[m]…＝説明[/]` のグレーの補足を付ける（例：「musl＝小さなC標準ライブラリ」「ISUCON：Webサービスを制限時間内に速くする競技」）
- 悪い知らせ（脆弱性・不振）は `boo`、よい知らせ（優勝・達成）は `kiran` とジャンプ。悪い知らせのシーンでは跳ねない
- 伝聞（ブログの報告など）は「〜そうなのだ」にする
- 最後のニュースは「最後は、ハッカーニュースで一番の反響。」のように反響の大きさで締めると番組らしい
